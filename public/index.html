Typing SVG API

Generate animated typing SVGs for your GitHub README.

Usage

GET /api/typing?text=YOUR+TEXT

Parameters

  • text - Text to display (default: "HELLO WORLD")
  • fontSize - Font size in pixels (default: 32)
  • width - SVG width (default: 600)
  • height - SVG height (default: 80)
  • color - Text color hex without # (default: E80000)
  • bg - Background color hex without # (default: 000000)
  • speed - Typing speed 1-10 (default: 3)
  • font - Font family (default: "Press Start 2P")

Example

/api/typing?text=HELLO+WORLD&color=E80000&bg=1a1a2e
